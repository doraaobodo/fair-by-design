# FAIR and AI Machine-Actionability (15 minutes)

Imagine an automated research assistant encounters your research object for the first time.

Can it determine what the object is, whether it is relevant, how to interpret it, and whether access or reuse is permitted?

**Discussion:** Which FAIR improvements help machines make these decisions? Which decisions still require human oversight?
