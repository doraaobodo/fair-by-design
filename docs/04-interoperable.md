# Interoperable (20 minutes)

Compare `Patient_ID` with `subject_id`, `ALL` with `Acute lymphoblastic leukemia`, and `M/F` with `0/1`.

Create a small data dictionary recording variable name, definition, type, unit, missing-value convention, and applicable controlled vocabulary.

**Open discussion:** What would a computer need to integrate these fields correctly across studies?
