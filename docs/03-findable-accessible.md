# Findable + Accessible (25 minutes)

Return to the sample dataset. Draft a descriptive title, short summary, keywords, creator attribution, and an identifier strategy.

Next, assume it contains sensitive patient-level information. Discuss what metadata can be public, what data requires authorization, and how a prospective user requests access.

**Open discussion:** What is the minimum metadata another researcher needs to discover the research object without exposing protected information?
